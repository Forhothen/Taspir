# Taspir — первая сцена

Unity 6000.6.6f1, Universal Render Pipeline, Input System.

## Запуск

1. Открой в Unity Hub папку этого репозитория (не вложенную `Taspir`).
2. В окне Project открой `Assets/Scenes/FirstPersonRoom.unity` двойным кликом.
3. Нажми Play, затем кликни внутри окна Game.
4. WASD — ходьба, мышь — обзор, Esc — освободить мышь.

Камера сразу находится внутри комнаты. Для управления нужен клик: браузеры
разрешают захватывать мышь только после действия пользователя.

## Объекты в Hierarchy

- **Room** — пустой родитель для шести частей комнаты, внутренний размер 10×10×10 метров.
- **Floor, Ceiling и четыре Wall** — обычные кубы, растянутые в плиты.
  У каждого есть Mesh Renderer (показывает поверхность) и Box Collider (не даёт пройти насквозь).
- **Player** — игрок без видимого тела. Character Controller задаёт капсулу
  высотой 1,8 метра, которая сталкивается с полом и стенами.
- **Player Camera** — дочерняя камера на высоте глаз 1,65 метра.
  Audio Listener на ней — точка, из которой игрок будет слышать звук.
- **Room Light** — точечный источник света внутри комнаты.

Rigidbody здесь не нужен. Он подходит для объектов, которые должны двигаться
под действием физических сил. Для простой ходьбы используется Character Controller;
неподвижным стенам достаточно Box Collider. Гравитация игрока задана в скрипте.

## Код и материал

- `Assets/Scripts/FirstPersonController.cs` — единственный игровой скрипт.
  Читает клавиатуру и мышь через Input System, двигает игрока, поворачивает камеру,
  применяет гравитацию и управляет захватом курсора. Скорость и чувствительность
  можно менять в Inspector у Player. Движение по диагонали не ускоряет игрока.
- `Assets/Editor/FirstPersonSceneBuilder.cs` — вспомогательный скрипт редактора.
  Создаёт сохранённую сцену и материал через меню **Taspir → Create First Person Room**.
  Для обычного запуска использовать это меню не нужно. Повторный запуск пересоздаст
  комнату и назначит её стартовой сценой сборки. В игру этот скрипт не попадает.
- `Assets/Materials/ForestGround.mat` — материал URP/Lit для стен и пола.
  Цветовая текстура показывает лесную почву, normal map имитирует мелкий рельеф
  при освещении, не изменяя геометрию или столкновения. Текстура повторяется 5×5 раз.
- `Assets/Textures/ForestGround` — две текстуры 1024×1024 и сведения об источнике.

## Сборка для браузера

Сцена FirstPersonRoom назначена стартовой в списке сцен сборки.
Открой File → Build Profiles, выбери Web и переключись на него (Switch Platform).
Если Web отсутствует, установи Web Build Support для этой версии через Unity Hub.
Для локальной проверки используй Build And Run: веб-сборке нужен HTTP-сервер,
открывать index.html напрямую с диска не следует.
